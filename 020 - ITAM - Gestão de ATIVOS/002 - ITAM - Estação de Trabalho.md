# Conjunto mínimo recomendado para começar

Se você quiser começar de forma enxuta, eu criaria inicialmente apenas estes 18 campos:

### Identificação

- Nome do Ativo
- Hostname
- Número de Série
- Fabricante
- Modelo
- Tipo do Ativo

### Responsabilidade

- Usuário Principal
- Departamento
- Unidade

### Situação do Ativo

- Status
- Data da Última Sincronização

### Dados Técnicos

- Sistema Operacional
- Versão do Sistema Operacional
- Processador
- Memória RAM
- Armazenamento Total
- Endereço IP
- Endereço MAC

Esse conjunto já permite responder às perguntas mais comuns do suporte, da gestão e da auditoria sem transformar o TOPdesk em um repositório excessivamente detalhado de informações coletadas pelo OCS Inventory.
